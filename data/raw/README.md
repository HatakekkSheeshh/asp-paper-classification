# Raw Data

Thư mục này dành cho dữ liệu raw đã được chuẩn hóa tên file.

## Trạng thái hiện tại

- Chưa copy dữ liệu sang đây.
- Dữ liệu gốc nhóm đang có vẫn ở `dataset_stage1/`.

## Quy ước khi chuẩn hóa

- `train_stage1.csv`
- `test_stage1.csv`

Nếu nhóm chuyển dữ liệu sang đây trong tương lai, hãy cập nhật `configs/experiment_config.yaml` để toàn bộ notebook và module dùng chung một nguồn.
