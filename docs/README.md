# Docs

Thư mục tài liệu dùng để thống nhất cách làm giữa các thành viên.

## File quan trọng

- `roadmap_kaggle_data_mining_team4.md`: roadmap mới theo mô hình 4 branch độc lập, 4 full pipeline, chọn winner branch.
- `cv_strategy.md`: luật validation dùng chung để so branch công bằng.
- `branching_strategy.md`: quy ước branch battle, commit và merge cuối kỳ.

## Tinh thần làm việc hiện tại

- Không chia cứng theo module nữa.
- Mỗi người tự làm end-to-end trên branch riêng.
- Cả nhóm chỉ dùng cùng luật về data, CV, tracker và submit format.
- Sau cùng chọn branch có kết quả mạnh nhất để làm bài chính.

## Khuyến nghị

- Khi có thay đổi ảnh hưởng đến luật chơi chung, hãy cập nhật docs trước hoặc cùng lúc với code.
- Không đổi CV strategy hoặc tiêu chí so branch giữa chừng nếu cả nhóm chưa thống nhất.
