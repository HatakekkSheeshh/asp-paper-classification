# Reports

Thư mục này chứa các file viết phục vụ báo cáo và thuyết trình.

## File hiện có

- `eda_summary.md`
- `error_analysis.md`
- `final_report.md`
- `figures/`

## Gợi ý workflow

- Insight từ notebook nên được chắt lọc lại ở đây bằng tiếng Việt rõ ràng.
- Không biến notebook thành báo cáo cuối; notebook để thử nghiệm, `reports/` để kể câu chuyện.
